# Homebrew tap for Tessel

[Tessel](https://tessel-lang.syncster.dev) is a small, compiled language for
building native apps, with the UI written in the language itself.

```sh
brew install alexiusacademia/tessel/tessel
```

`brew upgrade tessel` (or `tessel update`) brings it up to date. It's for
Macs with Apple silicon. Other ways to install, and Windows:
[Installation](https://tessel-lang.syncster.dev/start/installation/).

The formula is updated by Tessel's release workflow with each release.
